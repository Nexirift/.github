Nexirift is a software collective ran by a few passionate individuals. We aim to provide open social media without platform lock-in.

We are currently working on "Nexirift Reboot" with a handful of previous team members, the new specification can be found [here](https://git.codeguilds.org/Nexirift/spec).

## Contributing

If you are interested in helping us develop, we are more than happy to accept you as a contributor!

Please read the [contributing](./contributing/CONTRIBUTING.md) guide before making any changes.
