## Branches and pull requests

Even if you have access to push directly to the `main` branches, please refrain from doing so if possible.

Instead you should create your own branch, preferably a new one for each feature, and utilise pull requests.

These pull requests should be reviewed ideally by at least two other contributors before being merged.

## Before commiting, please...

- Follow the [Branches and pull requests](#branches-and-pull-requests) information above
- Run the proper check command, usually: `pnpm check`
- Run the proper format command, usually: `pnpm format`
- Follow the [Conventional Commits](https://www.conventionalcommits.org/en/v1.0.0/#specification) specification
