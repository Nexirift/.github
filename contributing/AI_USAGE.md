# AI Usage

**Last Updated:** 15th of October 2026 at 12:00 PM (ACDT)

This document outlines the procedures that must be followed when using Artifical Intelligence (AI, LLMs) in Nexirift projects.

## Rules

- You must be able to articulate all changes and code written by an LLM.
- Using solely AI ("vibe-coding") to develop a feature is strictly prohibited.
- Any usage of AI outside of the following conditions must be disclosed:
  - Auto Complete / IntelliSense
  - Translations for issue/PR descriptions only

## Disclosure

As mentioned above, AI usage outside of specific exceptions must be disclosed.

In pull requests and issues, write a short description **in your own words** about how AI was used.

## LLMs

Here is a sample list of covered LLMs:

- Anthropic: Claude
- GitHub/Microsoft: Copilot
- OpenAI: ChatGPT
- DeepSeek: All
- "X": Grok, Cursor

The scope of this document is not just limited to these. These are listed for your convenience if you are confused.
